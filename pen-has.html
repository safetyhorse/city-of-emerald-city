:has() — the selector that looks up

Every selector you already know looks down the tree: a parent styles its children. :has() is the first that looks up — style an element by what it contains. That upward reach is the exact thing JavaScript used to do; on the "before" page, jQuery walked the DOM with .closest() to pull it off.

1. Style a parent by what it contains

Check any service — the whole row reacts, because the row contains a checked box.

.option:has(:checked) { border-color: var(--brand); … }

2. React at a distance

Tick the box — a field appears below it. The field isn't inside the checkbox; the whole form notices and reveals it.

Phone number
.demo:has(#callback:checked) .callback-field { display: grid; }

3. The upward look that replaced jQuery

Type a bad email address and click away. The whole field group lights up — no submit handler, no .closest().

Email Please enter a valid email address.
.field:has(:user-invalid) input { border-color: var(--danger); }
