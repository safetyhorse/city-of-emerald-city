Still solid — trust what you already know

Modern CSS is mostly additive. These fundamentals did not change; if you learned them once, they still hold.

What you knowWhy it's still true
The box modelcontent / padding / border / margin is unchanged. box-sizing: border-box is just the sane default now.
The cascade & specificityStill the core engine. Cascade layers organize it; they don't replace it. Source order still breaks ties.
Class selectors & BEMClasses are still your main tool. Naming conventions are still valid (just no longer the only way to scope).
Flexbox & Grid mental modelThe fundamentals are stable. Subgrid and container queries extend them; they don't restart them.
rem / emStill the right units for type and spacing. New units (ch, dvh, lh) add options, they don't retire these.
position: relative/absolute/fixed/stickySame behavior as ever. sticky is the newer member and is fully reliable.
z-index & stacking contextsSame rules. Just remember many properties silently create a stacking context (see the quiver below).
Pseudo-classes: :hover, :focus, :checked, :nth-childBread and butter, unchanged. The new relational ones (:has) build on top.
Transitions & keyframesSame model. New entry/exit animation features add to it; the basics are untouched.
Semantic HTMLMore valuable than ever — :has(), form pseudo-classes, and accessibility all reward good markup.

Not dead — just for the right job

The Delete List retires these from overuse, not from existence. Each still has a legitimate, narrower role. Don't overcorrect.

ToolStill the right choice forStop using it for
floatWrapping text around a figure or pull-quote — its original purpose.Page or component layout (use Grid/Flexbox).
Media queriesPage-level concerns: overall shell, print, prefers-reduced-motion, prefers-color-scheme, prefers-contrast, orientation.Component-level sizing (use container queries). They coexist — different jobs.
!importantUtilities that must always win (.hidden), overriding third-party or inline styles you can't edit, some a11y overrides.Winning ordinary cascade fights (that's a layers/specificity smell).
TablesTabular data — always correct, accessible, and expected.Page layout (never).
IDsFragment links (#section) and JS hooks.Styling hooks, if their specificity weight causes fights (or wrap in :where()).
Sass / preprocessorsMixins, functions, loops, the @use module system, build-time math.Nesting and variables alone — CSS does those natively now.
jQueryExisting code that works — no need to rip it out on a deadline.Reaching for it in new code (native DOM APIs + CSS cover most of it).

Keep in the quiver — modern additions worth knowing

These don't replace an old hack — they're tools most people with 2011-era skills simply never met. Worth having in your back pocket.

ToolWhat it's forBaselineReference
isolation: isolate Create a stacking context with no z-index — the clean fix for z-index leaks between components. WIDELY isolation
@supports Feature-detect in CSS and enhance progressively — the key to adopting NEWLY features safely. WIDELY @supports
:is() / :where() Group selectors. :where() adds zero specificity — perfect for resets and defaults you want easy to override. WIDELY :where()
min() / max() / clamp() Not just for font size — use them for padding, widths, gaps, anywhere a value should flex. WIDELY clamp()
inset Shorthand for top/right/bottom/left; plus logical inset-block / inset-inline. WIDELY inset
object-fit / object-position background-size: cover behavior for real <img> elements — crop without a wrapper. WIDELY object-fit
min-content / max-content / fit-content Intrinsic sizing keywords — size a box to its content instead of guessing pixels. WIDELY Intrinsic sizing
currentColor Reuse the element's text color for borders, icons, and SVG fills — one value, stays in sync. WIDELY currentColor
:not(a, b, c) :not() now takes a list — "everything except these" in one selector. WIDELY :not()
scroll-snap Carousels and snap-to galleries with no JavaScript — scroll-snap-type + scroll-snap-align. WIDELY scroll-snap
@property Typed custom properties — unlocks animating variables and gradients the browser otherwise can't tween. WIDELY @property
@scope Scope styles to a subtree without naming conventions — a lighter alternative to BEM for isolated components. NEWLY @scope
content-visibility Skip rendering work for offscreen content — a cheap performance win on long pages. NEWLY content-visibility
The stacking-context reminder: a z-index that "won't work" is almost always a stacking-context problem, not a too-small-number problem. transform, filter, opacity < 1, will-change, backdrop-filter, and container-type all silently create one. Reach for isolation: isolate to make a component's stacking self-contained on purpose.
