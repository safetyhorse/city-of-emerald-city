Modern typography: clamp() and text-wrap

Two features that each delete a pile of old workarounds: clamp() makes type fluid in one line instead of a breakpoint ladder, and text-wrap lets the browser balance heading lines and kill orphan words instead of hand-placed <br> tags.

1. clamp() — fluid type in one line

Drag the box. The green heading scales smoothly with the container; the gray one jumps in steps at fixed breakpoints — the old @media ladder. Same range, one line vs. four rules.

.fluid { font-size: clamp(1.5rem, 1rem + 4cqi, 3rem); } /* min 1.5rem · grows with the container · max 3rem */

2. text-wrap: balance & pretty

Drag to a width where the headings wrap to 2–3 lines. Balance evens the line lengths; the default leaves a lopsided last line. Pretty keeps a lone word off the last line of body text.
