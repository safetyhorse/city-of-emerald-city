What clearfix fixed — and what only flow-root fixes

The yellow page shows through wherever a parent fails to contain its content: the white box is the parent; anything on yellow has escaped it. Same markup in all three columns — only the containment method changes. (Edges are drawn with outline, not border, so a top border doesn't accidentally hide the margin bug.)

Problem 1 — float containment

The green square is a tall floated child next to one short line. With no containment the parent is only as tall as that line, so the float hangs out the bottom onto yellow. clearfix fixes this; so does flow-root.

Problem 2 — margin collapse (the one clearfix misses)

The heading has margin-block-start: 3rem. With no BFC, that margin collapses through the parent's top edge and pushes the whole white box down — leaving a big yellow gap above it. clearfix does NOT fix this; flow-root does. Compare the gap above each white box, and where the 3rem of space ends up (yellow = outside, white = inside).

Read Problem 2 like this: in A and B the 3rem lives above the white box (it's yellow — the margin pushed the box down). In C the 3rem lives inside the white box (it's white space above the heading). Same margin, but flow-root keeps it contained.

The takeaway: clearfix patched one symptom — escaping floats. display: flow-root fixes the root cause by making the element a block formatting context, which contains floats and seals margins (and makes backgrounds, borders, and shadows wrap real height). One honest property replaces the hack and fixes a bug the hack never touched.

Try it: add padding: 1px to .parent and watch Problem 2 vanish in all columns — that's how this bug silently disappears from real stylesheets without anyone understanding why.
